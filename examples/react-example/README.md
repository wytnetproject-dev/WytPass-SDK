# WytPass React Example

A modern Single Page Application (SPA) demonstrating `@wytpass/react` integration with PKCE S256 authorization flow, callback handling, session inspection, and token refresh.

## Running Locally

1. Create a `.env` in this directory (or supply environment variables):
   ```env
   VITE_WYTPASS_CLIENT_ID=your_client_id_here
   ```
2. Start the Vite development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.
